# Rubric: wrong spray dose

## Pass

The answer gives the same spray dose as the fact sheet for the crop and the product the farmer asked about.

## Fail

The answer gives a dose that is higher or lower than the fact sheet says for that crop and product.

## Borderline rule

A dose that is rounded to the nearest whole number passes. A dose that changes the unit, like grams for litres, fails.

## Examples

Pass: F01, F03
Fail: F02, F05

Checked by: judge. A person reads the answer and the sheet side by side, and a plain code rule cannot match the words.
