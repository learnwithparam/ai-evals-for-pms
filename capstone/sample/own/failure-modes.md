# Failure modes in a shop returns assistant

These are traces from a shop returns assistant. It answers customers from the returns policy page.

## Wrong refund window

Definition: The answer gives a number of days that is not the number on the policy page.
Traces: R02, R05, R12

## Wrong postage rule

Definition: The answer says the shop pays return postage when the policy says the customer pays.
Traces: R04, R09, R19

## Worn item accepted

Definition: The answer says a worn item can come back when the policy says unworn only.
Traces: R14, R16, R19

## Answers a different question

Definition: The answer is about shipping or gift cards when the customer asked about a refund.
Traces: R07, R10, R17
