# Rubric: wrong refund window

## Pass

The answer gives the same number of days as the policy page for the item the customer asked about.

## Fail

The answer gives a number of days that is higher or lower than the policy page says.

## Borderline rule

A window said as one month passes when the policy says 30 days. A window with no number at all fails.

## Examples

Pass: R01, R03
Fail: R02, R05

Checked by: code. The refund window is a number, so a plain rule can compare it with the policy page.
